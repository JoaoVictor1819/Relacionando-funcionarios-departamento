# Sistema de controle de funcionarios

## Sistema simples de controle de funcionario que abranje: 
- Funcionarios
- Departamento 
- Projetos
- Endereco de funcionarios

### este sistema busca mostrar uma das principais coisa de uma api que sao os relacionamentos jpa e nessa api foram explorados as principais relacoes:
- @OneToOne 
- @ManyToOne 
- @ManyToMany

## As principais dependencias utilizadas nesta api foram:
### Spring start web
- para simplificar a criacoes de aplicacoes web
### Spring boot devtools
- para aumentar a produtividade durante o desenvolvimento de aplicacoes Spring boot
### Spring doc
- para realizar as documetacoes com o swagger
### Spring boot start validation
- para tratar com validacoes 
### Spring data jpa
- para facilitar a implementacao de camada de acesso a dados em aplicaoes java
### mysql
- Drives para poder o banco de dados mysql
### lombok
- Aumentar a produtividade e reduzir a vebosidade do codigo
